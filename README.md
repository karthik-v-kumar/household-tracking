# Stocked

Shared household grocery lists and pantry inventory.

Built for a two-person household that was using iPhone Reminders — and tired of
re-adding the same weekend items, splitting lists by store, and forgetting when
bulk goods like toilet paper were running out.

## What it does

- **Lists per store.** Grocery, warehouse, pharmacy — as many as you shop.
- **Usuals.** Star items you buy every weekend. Next week, add them back in one tap instead of retyping.
- **Clear bought.** Checking off an item does not delete the memory of it. After the trip, clear bought items; usuals stay in the catalog.
- **Inventory.** Track bulk / slow-burn goods with Full / Okay / Low / Out. Set a typical lifespan so the app can warn you before you run out. One tap adds low items to the right list. Buying them restocks inventory.
- **Household sharing.** Create a household, share a short invite code. Both people stay signed in on their phones and see the same data.

## Accounts

Sign in with Google, X, or email and password. Sessions persist on the device after the first login.

## Data

Household lists, catalog (usuals), and inventory live in Postgres.
